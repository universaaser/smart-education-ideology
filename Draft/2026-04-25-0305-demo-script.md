# Demo Script

## 结论

本脚本覆盖 PRD 第 10 包要求的教师、学生、知识库更新、管理员四条演示主线。所有步骤只引用当前已实现页面，不包含摄像头、视觉分析、Playwright 自动化等未完成能力。

## 演示前准备

- 启动 MySQL、后端 `8080` 和前端 Vite。
- 确认已执行主 `schema.sql` 或所需 `migration_*.sql`。
- 准备教师、学生、管理员三个角色；仓库无固定 seed 账号，按 README 注册或在本地演示库中设置 `ADMIN`。
- 准备一份课程文档，格式可为 `pdf/doc/docx/ppt/pptx/xls/xlsx/md/markdown`。
- 如需稳定 AI 输出，确认本地 OpenAI-compatible 服务可用；如不可用，演示时说明 fallback 或失败提示。

## 主线一：教师上传、生成与课程资源

| 步骤 | 页面 | 操作 | 预期结果 |
| --- | --- | --- | --- |
| T1 | Login/Register | 使用教师账号登录 | 进入教师 Shell，左侧出现 Dashboard、Resource Upload、Course Library 等菜单 |
| T2 | Resource Upload | 选择课程和章节，上传课程文档 | 出现解析任务状态、Parse History 或结果详情 |
| T3 | Resource Upload | 等待解析、知识点提取、思政匹配与教学生成 | 页面显示结构化解析结果、知识点、思政融入与教学材料草稿 |
| T4 | Resource Upload | 编辑 Lecture Notes、Teaching Cases、Assessment Questions、Ideology Integration | 草稿内容可修改并保存 |
| T5 | Resource Upload | 保存正式版本或查看预览 | 生成教学材料版本，可看到模板化预览或导出 Markdown |
| T6 | Course Library | 打开对应课程与章节 | 可看到课程材料、版本、预览、导出和继续编辑入口 |
| T7 | Knowledge Graph | 打开图谱并选择节点 | 抽屉展示节点信息、入边/出边和相邻节点 |
| T8 | Knowledge Graph | 对真实关系修改类型、删除，再点击 Undo Relation Change | 真实关系可编辑/删除，撤销后重新加载图谱；负 id 合成关系显示只读 |
| T9 | Student Alerts | 生成或查看学生预警 | 可看到预警汇总、等级分布、列表与处理状态入口 |

## 主线二：学生学习支持

| 步骤 | 页面 | 操作 | 预期结果 |
| --- | --- | --- | --- |
| S1 | Login/Register | 使用学生账号登录 | 进入学生 Shell，左侧出现 Student Home、Course Library、Knowledge Graph、AI Assistant |
| S2 | Student Home | 查看学习报告 | 显示今日学习时长、事件数、知识点访问数、趋势和反馈建议 |
| S3 | Course Library | 打开管理员已绑定课程 | 仅展示该学生绑定课程下的资源和材料 |
| S4 | Course Library | 打开课程材料或预览内容 | 触发资源打开行为上报，页面展示材料内容 |
| S5 | Knowledge Graph | 点击知识节点 | 触发知识点查看行为上报，抽屉展示节点详情 |
| S6 | AI Assistant | 输入课程相关问题 | AI 返回答案；如知识库命中，展示引用或检索状态 |
| S7 | Student Home | 返回首页刷新 | 最近活动、学习事件和反馈建议可体现新行为，具体数值取决于上报与后端聚合 |

## 主线三：知识库更新与审核

| 步骤 | 页面 | 操作 | 预期结果 |
| --- | --- | --- | --- |
| K1 | Source Management | 新增或编辑知识来源 | 来源配置保存成功，可启停 |
| K2 | Source Management | 手动触发指定来源抓取 | 生成运行日志；网络失败时应看到失败状态或错误信息 |
| K3 | Source Management | 审核抓取资源 | 资源可标记为 APPROVED 或 REJECTED；课程资源和聊天检索默认只读取 APPROVED 资源 |
| K4 | Keyword Tasks | 创建课程关键词任务 | 任务记录创建成功，绑定课程与关键词 |
| K5 | Keyword Tasks | 运行任务 | 系统从已审核资源中检索并生成 AI 摘要；外部失败时保留错误提示 |
| K6 | Keyword Tasks | 接受可用结果 | 结果进入资源库或复用既有资源，避免重复来源冲突 |
| K7 | Match Review | 查看待审核专业知识-思政匹配 | 列表展示匹配项、状态和历史入口 |
| K8 | Match Review | 批准、拒绝或修改匹配 | 状态与审核历史更新；Knowledge Graph 和 RAG 只使用 APPROVED 匹配 |
| K9 | Knowledge Graph | 查看合成思政关系 | 已批准匹配以只读合成关系展示，不能编辑或删除 |

## 主线四：管理员配置与课程绑定

| 步骤 | 页面 | 操作 | 预期结果 |
| --- | --- | --- | --- |
| A1 | Login/Register | 使用管理员账号登录 | 进入管理员可见菜单，出现 Admin Console 和 Model Settings |
| A2 | Admin Console | 查看用户分页列表 | 可看到用户、角色、状态等信息 |
| A3 | Admin Console | 创建教师、学生或管理员用户 | 用户保存成功；密码由后端加密保存 |
| A4 | Admin Console | 编辑用户信息或启停用户 | 状态变化在列表中可见；禁用用户不应继续作为演示账号使用 |
| A5 | Admin Console | 为课程添加学生绑定 | 学生端 Course Library 只看到绑定课程 |
| A6 | Admin Console | 移除课程学生绑定 | 学生端刷新后不再看到该课程资源 |
| A7 | Model Settings | 查看 provider 和 route 配置 | 可看到模型供应商、密钥配置状态和场景路由 |
| A8 | Model Settings | 保存 provider 或 route 设置并测试连接 | 配置可保存；连接测试结果取决于外部服务可用性 |

## 截图建议

- 教师上传解析完成页：展示结构化结果和教学材料草稿。
- Course Library：展示章节分组、材料版本、预览与导出。
- Knowledge Graph：展示关系治理抽屉和撤销按钮。
- Student Home：展示学习报告与反馈建议。
- Source Management / Keyword Tasks / Match Review：展示知识库更新与人工审核闭环。
- Admin Console / Model Settings：展示管理员控制台和模型路由配置。

## 风险与注意事项

- 真实浏览器手动验收仍需在答辩机器上执行一次。
- AI、MinerU、外部抓取和 Qdrant 都依赖本地或外部服务；不可用时应演示失败提示、fallback 或已准备的本地数据。
- 当前学生监测不包含摄像头和视觉模型，不能演示为已完成能力。
- 当前管理员权限主要覆盖菜单与关键页面，接口级全局权限仍是后续安全项。
- 当前无固定演示账号 seed，演示前必须按 README 准备账号与课程绑定。
