# Admin Console

## 结论

完成 PRD 第 8 包“管理员控制台：用户、课程、学生绑定”的 demo 闭环：管理员可进入 `Admin Console` 管理用户、启停账号、维护课程学生绑定；学生端课程资源库按绑定课程过滤。

## 改动原因

- 对应 `/Draft/毕设.md` 的角色管理、课程资源访问和学生学习支持闭环。
- 对应 `Draft/PRD.md` 第 8 包 8.1-8.7。

## 具体改动

- 新增 `course_students` 表、实体、Mapper、迁移脚本，并同步主 `schema.sql`。
- 新增 `AdminController`、`AdminUserService`、`CourseStudentService` 及相关 DTO，提供用户分页/创建/编辑/启停、课程学生绑定/移除和学生课程读取接口。
- 前端新增 `views/AdminConsole.tsx`，接入 `ADMIN_CONSOLE` view、菜单、admin 能力位和懒加载路由。
- `ResourceLibrary` 对学生端改用 `/api/courses/student/{studentId}`，教师/管理员保持原课程列表。

## 方案取舍

- 第一版仅做课程-学生多对多绑定，不引入班级/组织树，避免扩大范围。
- 用户禁用复用既有登录状态校验，不额外改认证主链路。
- 后端接口暂未做全局 admin 拦截，沿用当前项目前端菜单与能力位的 demo 权限边界。

## 风险与注意事项

- 目标数据库仍需执行 `migration_course_students.sql`。
- 未做浏览器端真实登录手动验收。
- 接口级 admin 权限、教师课程归属管理、班级/组织管理仍是后续项。

## 验证情况

- `mvn -f backend/pom.xml -Dtest=AdminControllerTest,CourseControllerTest test`：18 tests，0 failures，BUILD SUCCESS。
- `npm run build`：通过，生成 `AdminConsole` 懒加载 bundle。
- 代码审查修复：非法 role 过滤不再归一为 `TEACHER`；清理 Admin Console 未使用导入。
