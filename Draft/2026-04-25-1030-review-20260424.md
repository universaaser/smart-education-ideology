# Review 20260424 Feature Changes

## 结论

已审查 `2026-04-24-2312-student-learning-report` 起的功能扩展，并完成必要修复。当前后端测试、前端类型检查和前端构建均可通过，学生学习报告、预警反馈和课程资源闭环的主要入口已恢复可达。

## 改动原因

- 本轮属于对 `/Draft/毕设.md` 中“学生学习支持与预警”“智能教学内容生成”“课程资源闭环”的目标功能缺陷修复。
- 审查发现人工校正链路未同步题目结构化字段、学生角色不能默认进入学生首页、学生资源库看不到课程材料、前端缺少 Vite 类型声明，均会影响运行或维护。

## 具体改动

- `ParseTaskCorrectionService.java`：允许并规范化题型、难度、知识点 ID 和选项字段，避免人工校正保存结构化题目时报错。
- `RoleAccessService.java` 与 `RoleAccessServiceTest.java`：学生默认视图改为 `STUDENT_HOME`，并补回归测试。
- `ResourceLibrary.tsx`：学生端加载并只读展示已发布课程材料，隐藏教师导出和继续编辑入口。
- 新增 `vite-env.d.ts`，补齐 `import.meta.env` 类型。
- 同步维护本审查文档、验收清单和变更索引。

## 方案取舍

- 采用局部修补，没有重写资源库、角色权限或教学材料模型。
- 题目字段规范化复用既有取值口径，非法值回退到现有默认值，降低对旧数据和草稿的影响。
- 学生资源库只开放已发布版本，避免把教师草稿、导出和编辑能力暴露给学生。

## 风险与注意事项

- 尚未做真实浏览器手动验收，学生首页、课程材料预览、资源打开埋点、预警反馈仍需按 demo 脚本手点。
- 接口级权限仍是既有风险，当前主要依赖角色能力和前端入口收口。
- 多个迁移脚本仍需在真实 MySQL 环境按顺序执行并检查重复索引风险。
- AI provider/route 的 DB 配置仍未接入运行时热切换。
